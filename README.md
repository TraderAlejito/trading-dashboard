# Trading Dashboard

Dashboard para el sistema de trading con prop firms.

## Features

- Trades del dia con botones TP/SL
- Rolling 6M con umbral 30% WR
- Gestion de cuentas y payouts
- Historial de trades
- Estadisticas historicas (2015-2026)
- Configuracion de setups
- Responsive (mobile + desktop)

## Deploy en Vercel

1. Subi este folder a GitHub
2. En Vercel, importa el repo
3. Deploy automatico

## Desarrollo local

```bash
npm install
npm run dev
```

## Configuracion

- Rolling: 6 meses mensual
- Umbral: 30% WR
- Challenge: $130
- TP Challenge: $1,500
- Funded: $1,500
- Dias minimos: $160
